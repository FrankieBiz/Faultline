FaultLine is a controlled source-repair platform targeting silent e-commerce checkout crashes. When customers buy without a coupon, the server crashes with an unhandled TypeError. FaultLine captures the failure in headless Chromium, prompts Meta's Model API under strict AST blast-radius constraints, and verifies the candidate inside isolated Linux namespaces and kernel cgroup limits before issuing a verifiable result.
