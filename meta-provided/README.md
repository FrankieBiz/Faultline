# Protected source artifacts

Everything in this directory is an immutable source artifact. **Models and automated tools must not edit, rename, replace, reformat, or delete these files.** Write any transcription or analysis elsewhere in the repository. See the root `AGENTS.md` for the full rule.

`webinar/` contains the five screenshots Frankie supplied on October 26, 2026. The files are kept in their original image format. `SHA256SUMS` records their byte-level fingerprints so accidental changes can be detected.

The official pages are linked in `docs/HACKATHON_BRIEF.md`; consult them for current event details. This directory does not contain a copied or paraphrased substitute for the official rules.
